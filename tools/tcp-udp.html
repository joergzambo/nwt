Ports und Sockets

Ein Rechner hat eine IP-Adresse, aber viele Programme gleichzeitig. Damit die Daten beim richtigen Programm landen, bekommt jede Anwendung eine Portnummer. Die Kombination IP-Adresse + Port heißt Socket (z. B. 192.168.1.10:443).

  • Well-known Ports 0–1023: feste Dienste (HTTP 80, HTTPS 443, SSH 22 …).
  • Registered Ports 1024–49151: für Anwendungen registriert.
  • Dynamische/ephemere Ports 49152–65535: der Client wählt für jede Verbindung kurzfristig einen.
