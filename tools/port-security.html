Port Security

Port Security begrenzt, welche und wie viele MAC-Adressen an einem Switchport erlaubt sind. So lassen sich fremde Geräte, untergeschobene Switches und MAC-Flooding an der Zugangsschicht stoppen.

Wozu Port Security?

Ein Access-Port soll normalerweise genau ein Endgerät bedienen. Port Security sorgt dafür, dass nur bekannte oder nur eine begrenzte Zahl MAC-Adressen Frames senden dürfen.

  • Stoppt fremde Geräte, die jemand ans Netz steckt.
  • Verhindert MAC-Flooding (CAM-Overflow), weil pro Port nur wenige MACs erlaubt sind.
  • Verhindert untergeschobene Mini-Switches/Hubs (würden mehrere MACs bringen).
Port Security gibt es nur auf Access-Ports (und manuell gesetzten Trunks), nicht auf dynamischen Ports.

Konfiguration

! Port auf Access setzen und Port Security aktivieren
Switch(config)# interface fa0/1
Switch(config-if)# switchport mode access
Switch(config-if)# switchport port-security
Switch(config-if)# switchport port-security maximum 2
Switch(config-if)# switchport port-security mac-address sticky
Switch(config-if)# switchport port-security violation restrict
  • maximum N – wie viele MACs der Port lernen darf (Standard 1).
  • mac-address sticky – gelernte MACs werden automatisch in die running-config geschrieben (bleiben nach copy run start erhalten).
  • mac-address H.H.H – eine MAC fest erlauben (statisch).
  • violation MODE – was bei Überschreitung passiert (Standard shutdown).

Prüfen:

Switch# show port-security interface fa0/1
Switch# show port-security address

Die drei Violation-Modi

ModusFrames verworfenSyslog / CounterPort down?

Merke: protect = leise verwerfen, restrict = verwerfen + melden, shutdown = Port abschalten.

err-disabled und Recovery

Nach einer Verletzung im Modus shutdown ist der Port err-disabled – er bleibt dauerhaft unten, bis ihn jemand zurücksetzt:

! manuell zurücksetzen
Switch(config-if)# shutdown
Switch(config-if)# no shutdown

! oder automatisch nach 300 s wieder aktivieren
Switch(config)# errdisable recovery cause psecure-violation
Switch(config)# errdisable recovery interval 300
